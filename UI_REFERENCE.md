# UI reference & audit

## Existing-project audit (8 November 2026)

The supplied directory was a curated source library of BPSC TRE 1–3 PDFs. It had no frontend, backend, package manifest, screenshots, routing, styles, components, or existing API integration to preserve. This Vite + React + TypeScript application is therefore a new frontend shell. The source PDFs remain untouched. The demo questions in the interface are explicitly labelled practice samples, not verified PYQs.

## References considered

- [Quizlet Learn](https://quizlet.com/features/learn) — short adaptive practice, varied question formats, and focused sessions informed the direct “start practice” path.
- [Khan Academy mastery](https://support.khanacademy.org/hc/en-us/articles/115002552631-What-are-Course-and-Unit-Mastery) — topic-level mastery states and recommendations informed the restrained analysis view.
- [Testbook support](https://support.testbook.com/) — exam-like mocks and detailed analysis support an examination-oriented practice surface, but the dense dashboard pattern was deliberately not copied.

## Selected direction

“Quiet exam desk”: navy is used for navigation and focused actions, warm gold signals progress, and off-white surfaces reduce reading fatigue. The interface prioritizes one primary action at a time, a two-stage category → subject path, generous line-height for Hindi, clear timer/progress feedback, and responsive single-column controls. Community content stays attached to a question rather than a global chat.
